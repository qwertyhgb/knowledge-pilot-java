# KnowledgePilot 学习笔记

> **这里记录的不是"知识是什么"，而是"我怎么想错的、怎么验证的"。**
>
> 定义、原理这类内容书和文档里有，忘了去查即可；真正值钱的是**自己的错误认知**和
> **自己动手验证的过程**。所以本目录的笔记统一采用「先写下我原本以为什么 → 再记录实验
> 怎么做的 → 最后写面试怎么答」的结构。

---

## 怎么用这份笔记

1. **学完一个知识点** 就更新对应文件（不要新建碎片文件，一个主题一个文件）
2. **先写 `我原本以为` 那一栏** —— 哪怕写的是错的，错误认知最值钱
3. **顺手更新本文档的索引行**（进度、最后更新日期）
4. **git commit** —— 让提交历史成为学习历史

---

## 笔记模板

新建主题笔记时，复制以下骨架（本文档底部有完整模板文件）：

```markdown
# <主题名>

## 一、我原本以为（错的也照写）
## 二、实验怎么做的
## 三、我踩的坑
## 四、面试怎么答
## 五、❓ 待解答 / 以后要验证
## 六、还没学到
```
